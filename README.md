# Лабораторная 3

Приложение на C++17 и SFML 3.0.2. Сравнивает дискретную физику, непрерывное обнаружение столкновений (CCD) и multi-rate: обычные тела — 60 Гц, снаряды — 240 Гц.

## Сборка в Visual Studio 2022

### 1. Подготовьте инструменты

В Visual Studio Installer для Visual Studio 2022 установите рабочую нагрузку **«Разработка классических приложений на C++»**. Нужны компилятор MSVC v143 для x64/x86, Windows SDK и средства CMake для C++.

В папке `vendor/SFML-3.0.2` уже лежит библиотека SFML для Windows x64 / MSVC 2022, включая заголовки, библиотеки, DLL и лицензию. Отдельно скачивать SFML и вручную настраивать пути в Visual Studio не нужно. Для самой сборки интернет не требуется. Требуется CMake 3.24 или новее.

### 2. Откройте папку в Visual Studio 2022

Просто откройте папку. Cmake сделает сборку. Далее выберите MechanicsLab.exe как целевой объект отладки и запустите программу.

## Управление

Выберите опыт слева и нажмите **Старт**. Кнопка **Сравнить все** показывает три режима с одинаковыми начальными условиями. Нажатие на название режима открывает его крупнее.

| Клавиша | Действие |
|---|---|
| Пробел | Старт / пауза |
| N | Один базовый шаг |
| R | Сброс |
| 1 / 2 / 3 | Дискретный / CCD / multi-rate |
| C | Сравнение трёх режимов |


Слева можно менять скорость снарядов, упругость и частоту обычных тел. При 120 Гц обычных тел частота снарядов остаётся 240 Гц. Замедление воспроизведения не меняет шаг физики. Кнопка **CSV** сохраняет текущее состояние трёх миров.

## Опыты и ограничения

- **Тонкая стенка:** снаряд 6 × 6 px, стенка 10 px. При 2000 px/с дискретные 60 Гц пропускают стенку, CCD и multi-rate дают отскок. При 10 000 px/с multi-rate тоже может пропустить столкновение.
- **Система объектов:** 24 обычных тела, 2 снаряда, 5 препятствий и 4 внешние границы.
- **Устойчивость стопки:** 12 блоков и снаряд. В численном эксперименте снаряд убирается для отдельной оценки покоя стопки.

Тела представлены AABB — прямоугольниками без вращения. Нет трения, деформации и сопротивления воздуха. CCD использует постоянные скорости внутри шага после применения тяжести. Multi-rate приближённо учитывает движение обычных тел между их обновлениями. Внешние границы удерживают тела внутри арены в опытах 02 и 03; в опыте с тонкой стенкой такой защиты нет.
